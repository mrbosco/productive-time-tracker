## 2. UX patterns

| Pattern                                    | Who     | Where                                                                                                                                                                                                                                                 | Why it matters for this app                                                                                  |

### 2.3 Productive weaknesses to avoid

- Left column is permanently split between the form and an empty suggestions panel (P-DAY); on a mobile width this pushes the list below two panels. The take-home uses a single column with the list first.
- "Save as draft" as the primary button: the assignment has no draft concept (A-8), so the primary action is "Save".
- Delete without confirmation (A-10). Harvest and Toggl both confirm; the assignment requires it.
- Calendar view places an entry without start time as a chip at the top of the column (P-CAL), which is the honest rendering for minutes-only data. Not building a calendar view.
